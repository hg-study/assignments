# Tag

### Tag 정의

> Tag는 브라우저에게 콘텐츠를 어떻게 표시할지 지시하는 마크업 기호다. `<태그명>` 여는 태그와 `</태그명>` 닫는 태그 쌍으로 구성되며, 두 태그 사이의 내용 전체를 요소(Element) 라 한다. 닫는 태그 없이 혼자 사용하는 태그는 빈 요소(Empty Element) 라 한다. (예: `<br />, <hr />, <meta />`) 

<br>

---

## HTML 문서 기본 구조

| 태그 / 선언 | 역할 |
|---|---|
| `<!DOCTYPE html>` | 브라우저에게 HTML5 문서임을 선언. 반드시 문서 최상단에 위치 |
| `<html lang="ko">` | HTML 문서의 루트 요소. `lang` 속성으로 문서 기본 언어 명시 |
| `<head>` | 브라우저에 전달할 메타데이터 영역. 화면에 직접 표시되지 않음 |
| `<body>` | 실제 화면(ViewPort)에 표시되는 본문 영역 |

> **주석:** `<!-- 내용 -->` 형식. 브라우저가 무시하며 화면에 표시되지 않는다.

## Block vs Inline 요소

HTML 요소는 레이아웃 동작 방식에 따라 두 종류로 나뉜다.

| 구분 | 특징 | 대표 태그 |
|---|---|---|
| **Block** | 한 줄 전체를 차지, 다음 요소는 자동 줄 바꿈 | `h1~h6`, `p`, `div`, `ul`, `ol`, `li` |
| **Inline** | 콘텐츠 너비만큼만 차지, 같은 줄에 다른 요소와 공존 | `span`, `a`, `strong`, `em`, `br` |

> **Inline 요소의 제한:** 기본 상태에서 `width`, `height`, 상하 `margin` 이 적용되지 않는다.  
> `display: block`을 적용하면 Inline 요소를 Block처럼 동작시킬 수 있다.

<br>

### display 속성

| 값 | 동작 |
|---|---|
| `block` | Block 요소로 변환. width · height · margin 전체 적용 가능 |
| `inline` | Inline 요소(기본값). width · height · 상하 margin 미적용 |
| `inline-block` | 줄 바꿈 없이 width · height 적용 가능 |
| `none` | 요소를 화면에서 완전히 숨김 |

## 주요 태그 상세

#### 제목 태그 `<h1> ~ <h6>`
- **Block 요소**. 숫자가 클수록 글자 크기·강조 감소
- `h1` 은 페이지당 1개 권장 (SEO · 접근성 기준)

<br>

#### 단락 태그 `<p>`
- **Block 요소**. 위아래에 기본 `margin` 자동 적용
- 텍스트 단락을 표현할 때 사용

<br>

#### 컨테이너 태그 `<div>` / `<span>`

| 태그 | 종류 | 용도 |
|---|---|---|
| `<div>` | Block | 여러 요소를 묶어 영역을 나누는 레이아웃 컨테이너 |
| `<span>` | Inline | 텍스트 일부를 묶어 스타일을 적용하는 인라인 컨테이너 |

> `<div>`와 `<span>` 자체는 시각적 의미가 없다. CSS와 함께 사용해 레이아웃·스타일을 적용한다.

<br>

#### 빈 요소 (Self-Closing)
내용(content)이 없고 여는 태그만 존재하는 태그

| 태그 | 역할 |
|---|---|
| `<br />` | 줄 바꿈 (Line Break) |
| `<hr />` | 수평 구분선 (Horizontal Rule). Block 요소 |
| `<meta />` | 메타데이터 |
| `<img />` | 이미지 삽입 |
| `<input />` | 입력 필드. `type` 속성값에 따라 입력 방식이 달라진다. |

<br>

#### `<input>` type 속성

| 값 | 동작 |
|---|---|
| `text` | 일반 텍스트를 입력받는 기본 필드 (기본값) |
| `password` | 입력값이 화면에 가려져(●●●) 표시되는 필드 |
| `file` | 사용자 기기에서 파일을 선택해 업로드할 수 있는 필드 |
| `email` | 이메일 형식 검증이 포함된 필드. `@` 포함 여부 등 브라우저 자체 유효성 검사 |
| `checkbox` | 여러 항목 중 다중 선택이 가능한 체크박스 |
| `radio` | `name` 속성이 같은 그룹 내에서 단일 선택만 가능한 버튼 |

<br>

#### Form 관련 태그

`<input>`을 감싸 실제 데이터를 전송하는 폼 구성 태그들

| 태그 / 속성 | 종류 | 설명 |
|---|---|---|
| `<form action="">` | Block | 사용자 입력을 모아 서버로 전송하는 영역. `action`은 전송할 서버 측 경로(URL). 비워두면 현재 페이지 주소로 전송됨 |
| `<label>` | Inline | 입력 항목의 제목을 나타내는 텍스트 요소 |
| `<select>` | Inline-block | 여러 옵션 중 하나를 고르는 드롭다운 목록 |
| `<option value="">` | - | select 안의 개별 선택 항목. `value`는 폼 전송 시 서버로 실제 전달될 값. 비워두면 선택해도 빈 값이 전송됨 |
| `<button>` | Inline-block | 클릭 시 동작을 실행하는 버튼. `<form>` 내부에서는 기본 `type`이 `submit`이라 클릭 시 form 데이터를 전송 |
| `placeholder` | 속성 | 입력 전 빈 칸에 보여주는 미리보기 텍스트 |

<br>

## CSS Box Model

모든 HTML 요소는 아래 4개의 영역으로 공간이 구성된다.

```
┌─────────────────────────────┐
│          margin             │  ← margin: 바깥 여백 (다른 요소와의 간격)
│  ┌───────────────────────┐  │
│  │        border         │  │  ← border: 테두리 선
│  │  ┌─────────────────┐  │  │
│  │  │     padding     │  │  │  ← padding: 안쪽 여백 (content ↔ border)
│  │  │  ┌───────────┐  │  │  │
│  │  │  │  content  │  │  │  │  ← content: 실제 콘텐츠 (텍스트, 이미지 등)
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

| CSS 속성 | 설명 |
|---|---|
| `background-color` | 배경색 지정 |
| `width` / `height` | 너비 / 높이 (content 영역 기준) |
| `border` | 테두리. `두께 스타일 색` 순 작성 (예: `1px solid blue`) |
| `padding` | 안쪽 여백 |
| `margin` | 바깥쪽 여백 |

> **Inline 요소**는 Box Model에서 `width`, `height`, 상하 `margin`이 적용되지 않는다.

## 리스트 태그

#### 기본 구조

| 태그 | 이름 | 설명 |
|---|---|---|
| `<ul>` | Unordered List | 순서 없는 목록. 기본 마커: 점(•) |
| `<ol>` | Ordered List | 순서 있는 목록. 기본 마커: 숫자(1, 2, 3...) |
| `<li>` | List Item | ul 또는 ol의 개별 항목. 반드시 ul/ol 내부에서만 사용 |

> `ul`과 `ol` 모두 **Block 요소**이며, 기본적으로 들여쓰기(padding-left)가 자동 적용된다.

<br>

### `<ol>` type 속성 - 마커 형식 변경

| 값 | 마커 |
|---|---|
| `1` | 숫자 (기본값) |
| `a` | 소문자 알파벳 |
| `A` | 대문자 알파벳 |
| `i` | 소문자 로마 숫자 |
| `I` | 대문자 로마 숫자 |

<br>

### `<ol>` 추가 속성

| 속성 | 설명 |
|---|---|
| `start="숫자"` | 시작 번호를 지정 (예: `start="3"` → 3, 4, 5...) |
| `reversed` | 번호를 역순으로 표시 |

<br>

### 중첩 리스트
`<li>` 내부에 또 다른 `<ul>` 또는 `<ol>`을 삽입해 계층 구조를 표현한다.

```
ul (대분류)
├── li
│   └── ol (순서 있는 세부 항목)
│       ├── li
│       └── li
└── li
    └── ul (순서 없는 세부 항목)
        └── li
```

- 세부 항목이 **순서를 가질 때** → `ol` 중첩
- 세부 항목이 **순서 무관할 때** → `ul` 중첩
- 들여쓰기 depth에 따라 마커 모양이 자동으로 달라진다.
