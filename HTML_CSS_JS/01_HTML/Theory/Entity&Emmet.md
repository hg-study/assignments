# Entity&Emmet

### Entity 정의

> HTML은 `<`, `>`, `&` 같은 문자를 태그나 문법 기호로 인식한다. 이 문자들을 화면에 그대로 출력하려면 브라우저가 문자로 해석할 수 있는 특별한 코드로 변환해야 하는데, 이를 **엔티티(Entity)** 라 한다.

<br>

---

## Entity
<br>

**엔티티 표기 방식**

| 방식 | 형식 | 예시 |
|---|---|---|
| 이름 방식 | `&엔티티명;` | `&lt;` |
| 숫자 방식 | `&#숫자코드;` | `&#60;` |

<br>

**주요 엔티티 목록**

| 문자 | 이름 | 숫자 코드 | 설명 |
|---|---|---|---|
| `<` | `&lt;` | `&#60;` | less-than |
| `>` | `&gt;` | `&#62;` | greater-than |
| `&` | `&amp;` | `&#38;` | Ampersand |
| `"` | `&quot;` | `&#34;` | 큰따옴표 |
| `'` | `&apos;` | `&#39;` | 작은따옴표 (HTML5 이상) |
| ` ` | `&nbsp;` | `&#160;` | 강제 공백 (non-breaking space) |
| `©` | `&copy;` | `&#169;` | 저작권 기호 |
| `®` | `&reg;` | `&#174;` | 등록상표 기호 |
| `™` | `&trade;` | `&#8482;` | 상표 기호 |

<br>

> **참고:** HTML은 스페이스를 여러 번 입력해도 화면에는 한 칸만 표시된다. `&nbsp;`를 연속 사용하면 그 수만큼 강제 공백이 늘어난다.

##  Emmet

> Emmet은 HTML/CSS 작성 속도를 높이기 위한 단축 문법(Abbreviation) 도구다. VS Code에 기본 내장되어 있으며, 단축 문법 입력 후 `Tab` 키를 누르면 지정한 구조의 HTML 태그로 자동 확장된다.

<br>

**핵심 문법 요약**

| 문법 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `!` | HTML5 기본 구조 생성 | `!` | 기본 문서 구조 자동 생성 |
| `태그명` | 태그 생성 | `div` | `<div></div>` |
| `>` | 자식 요소 생성 | `div>ul>li` | div 안에 ul, ul 안에 li |
| `+` | 형제 요소 생성 | `ul+ol` | 같은 부모 아래 ul, ol |
| `^` | 부모 레벨 이동 | `div>ul>li^p` | li에서 벗어나 ul의 형제로 p 생성 |
| `*` | 요소 반복 생성 | `li*3` | li 3개 |
| `$` | 자동 순번 삽입 | `li*3{ITEM_$}` | ITEM_1, ITEM_2, ITEM_3 |
| `.` | class 속성 지정 | `div.box` | `<div class="box"></div>` |
| `#` | id 속성 지정 | `div#wrap` | `<div id="wrap"></div>` |
| `[]` | 속성 직접 지정 | `ol[type="I"]` | `<ol type="I"></ol>` |
| `{}` | 텍스트 삽입 | `span{hello}` | `<span>hello</span>` |
| `()` | 요소 그룹화 | `div>(header+footer)` | 요소를 묶어서 생성 |
| `lorem` | 더미 텍스트 생성 | `p>lorem` | Lorem Ipsum 자동 생성 |

<br>

> **태그명 생략 시** `.클래스명` 또는 `#아이디명`만 입력하면 기본값으로 `<div>`가 생성된다.  
> `^`를 연속 사용하면 그 수만큼 레벨을 거슬러 올라간다.
