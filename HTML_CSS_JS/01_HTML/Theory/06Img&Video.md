# Img & Video

### 이미지 삽입 기본

> `<img>` 태그는 이미지를 화면에 표시하는 태그로, `src`로 경로를 지정하고 `alt`로 대체 텍스트를 정의한다. 클릭 시 원본 보기 등 **동작이 필요**하면 `<a>`로 감싸 사용한다.

<br>

| **속성** | **설명** |
| --- | --- |
| `src` | 표시할 이미지의 경로(로컬 파일 또는 URL)를 지정하는 속성 |
| `alt` | 이미지를 표시할 수 없을 때 대체 텍스트. 스크린리더 등 접근성 도구에서도 사용된다 |

<br>

## 이미지 경로 방식

### 로컬 이미지 vs 외부 이미지

> 이미지 경로는 크게 로컬(프로젝트 내부) 경로와 외부(타 도메인) 경로로 나뉜다. 두 방식 모두 `src`에 경로 문자열만 넣으면 되지만 동작 조건이 다르다.

<br>

| **방식** | **경로 형태** | **설명** |
| --- | --- | --- |
| 로컬 이미지 | `./images/dog.jpg` | 프로젝트 폴더 내부에 저장된 이미지를 상대 경로로 불러온다 |
| 외부 이미지 | `https://...` | 다른 도메인 서버에 있는 이미지 경로를 직접 지정한다 |

<br>

외부 이미지는 해당 서버가 <span style="color:brown">핫링크(hotlink: 외부 도메인에서의 직접 접근)를 차단</span>해두면 이미지가 표시되지 않을 수 있다. 공개적으로 접근이 허용된 경로인지 확인이 필요하다.

<br>

- 예제 코드: [Img 삽입](../12Img.html)

## Base64 인코딩 이미지

### Base64 Encoding

> 이미지 파일 자체를 문자열로 변환해 `src` 속성 값에 직접 삽입하는 방식이다. 별도의 이미지 파일 없이 HTML 코드 안에 이미지 데이터를 포함시킬 수 있다.

<br>

| **구분** | **내용** |
| --- | --- |
| 장점 | 이미지 파일을 별도로 첨부하지 않아도 HTML 코드만으로 이미지가 표시된다 |
| 단점 | 문자열 길이가 매우 길어져 HTML 파일 전체 용량이 커진다 |

<br>

<span style="color:gray">보통 아주 작은 아이콘이나 외부 파일 의존을 피해야 하는 특수한 경우에 한해 제한적으로 사용한다.</span>

<br>

- 예제 코드: [Img 삽입](../12Img.html)

# Video

### YouTube 영상 임베드 (iframe)

> 외부 플랫폼(YouTube 등)의 영상은 `<iframe>` 태그를 이용해 현재 페이지 안에 인라인으로 삽입한다. embed 주소 뒤에 `?`, `&`로 쿼리 파라미터를 이어 붙여 재생 방식을 제어한다.

<br>

| **속성** | **설명** |
| --- | --- |
| `src` | 삽입할 페이지(영상)의 경로. embed 주소 뒤에 쿼리 파라미터로 옵션을 추가한다 |
| `title` | 스크린리더 등 접근성 도구에서 읽어주는 영상 제목 |
| `frameborder` | 프레임 테두리 두께. `0`이면 테두리 없음(CSS의 `border`로 대체 가능) |
| `allow` | iframe 내부 콘텐츠에서 사용을 허용할 브라우저 기능 목록(자동재생, 클립보드 등)을 지정 |
| `allowfullscreen` | 영상을 전체화면으로 전환할 수 있게 허용하는 속성 |
| `referrerpolicy` | 요청 시 Referer 헤더에 담길 출처 정보의 범위를 제어하는 속성 |

<br>

**src 쿼리 파라미터**

| **파라미터** | **설명** |
| --- | --- |
| `autoplay=1` | 영상을 자동으로 재생한다 |
| `mute=1` | 영상을 음소거 상태로 재생한다 |

<br>

<span style="color:gray">대부분의 브라우저는 음소거(mute) 상태가 아니면 자동재생을 차단하므로, `autoplay=1`은 보통 `mute=1`과 함께 사용한다.</span>

<br>

## 배경 동영상 재생

### video 태그 기본 옵션

> `<video>` 태그는 자체 동영상 파일을 재생하는 태그이며, 내부에 `<source>`를 두어 실제 파일 경로와 형식을 지정한다.

<br>

| **속성** | **설명** |
| --- | --- |
| `autoplay` | 페이지 로드 시 영상을 자동으로 재생한다 |
| `muted` | 영상을 음소거 상태로 재생한다 |
| `loop` | 영상이 끝나면 처음부터 반복 재생한다 |
| `controls` | 재생/정지 등 하단 제어부 표시 여부를 결정한다 |

<br>

### MIME TYPE

> Client와 Server 간 자료(주로 파일)를 교환할 때 사용되는 표준화된 식별자다. `type/subtype` 형식으로 구성된다.

<br>

| **구분** | **예시** | **설명** |
| --- | --- | --- |
| type | text, image, video, application | 자료의 큰 분류 |
| subtype | html, png, mp4, pdf | 분류 내 세부 형식 |

<br>

**Img & Video 구조 요약**

`<img src alt>` : 이미지 삽입 - 로컬/외부 경로 모두 가능, 외부는 핫링크 차단 가능성 있음<br>
Base64 인코딩 : 파일 없이 문자열로 이미지 삽입 - 용량 증가 단점<br>
`<iframe>` : 외부 플랫폼(YouTube) 영상 삽입 - src 쿼리파라미터로 autoplay/mute 제어<br>
`<video>` + `<source>` : 자체 동영상 파일 재생 - autoplay/muted/loop/controls 옵션<br>
MIME TYPE : `type/subtype` 형식의 표준 자료 식별자
