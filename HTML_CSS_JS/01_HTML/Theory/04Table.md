# Table

### 기본 테이블 구조

> HTML에서 표는 `<table>`을 최상위 컨테이너로 두고, 행(`<tr>`)과 셀(`<th>`, `<td>`)을 중첩해 격자 구조를 만든다.

<br>

| **태그** | **설명** |
| --- | --- |
| `<table>` | 표 전체를 감싸는 최상위 컨테이너. 모든 행과 셀이 이 안에 위치한다 |
| `<caption>` | 표의 제목을 정의하는 태그. `<table>` 바로 아래에 위치하며 표 상단에 표시된다 |
| `<tr>` | Table Row. 표의 가로 한 줄(행)을 정의한다 |
| `<th>` | Table Header. 열 제목 셀. 기본적으로 굵게(bold), 가운데 정렬로 표시된다 |
| `<td>` | Table Data. 일반 데이터 셀. 표의 실제 내용을 담는다 |

<br>

- 예제 코드: [기본 테이블](../07Table.html)

## 셀 병합


### rowspan / colspan

> 특정 셀이 여러 행 또는 열을 차지하도록 확장하는 기능이다. 병합된 자리의 `<td>`는 작성하지 않는다.

<br>

| **속성** | **방향** | **설명** |
| --- | --- | --- |
| `rowspan="N"` | ↓ 아래 | 해당 셀을 아래 방향으로 N개 행에 걸쳐 병합한다 |
| `colspan="N"` | → 오른쪽 | 해당 셀을 오른쪽 방향으로 N개 열에 걸쳐 병합한다 |

<br>

<span style="color:brown">병합된 자리의 `<td>`는 반드시 생략한다. 이미 해당 공간을 차지하고 있으므로 추가 작성 시 레이아웃이 오른쪽으로 밀린다.</span>

<span style="color:gray"> 병합 구조가 복잡할 경우 격자를 먼저 그려보고 어느 셀에 rowspan/colspan을 쓸지 계획한 뒤 작성한다.</span>

<br>

## 시맨틱 테이블

### thead / tbody / tfoot

> HTML5에서 테이블의 영역을 의미 있는 구획으로 나누는 시맨틱 태그다. 구조적 가독성과 접근성을 높이고, CSS로 영역별 스타일을 일괄 적용할 수 있다.

<br>

| **태그** | **역할** | **설명** |
| --- | --- | --- |
| `<thead>` | 헤더 영역 | 열 이름 등 제목 행을 감싼다. 항상 표의 최상단에 렌더링된다 |
| `<tbody>` | 본문 영역 | 실제 데이터 행들을 감싼다 |
| `<tfoot>` | 푸터 영역 | 합계, 요약 등 마지막 행을 감싼다. 항상 표의 최하단에 렌더링된다 |

<br>

**렌더링 순서 고정**: 코드 상 `<tfoot>`을 `<tbody>`보다 먼저 작성해도 브라우저는 항상 `<tfoot>`을 맨 아래에 표시한다. 코드 위치와 관계없이 `thead → tbody → tfoot` 순서를 유지한다.</span>

<br>

- 예제 코드: [시맨틱 테이블](../08Table.html)

<br>

**Table 구조 요약**

`<table>` : 표 전체 컨테이너  
`<caption>` : 표 제목 - `<table>` 바로 아래 위치  
`<thead>` / `<tbody>` / `<tfoot>` : 시맨틱 영역 구분 (렌더링 순서 고정)  
`<tr>` : 행 / `<th>` : 헤더 셀 / `<td>` : 데이터 셀  
`rowspan="N"` : 아래 방향 N칸 병합 / `colspan="N"` : 오른쪽 방향 N칸 병합
